# tools/ - 工具模块

实现 Agent 可调用的工具函数。

## 当前工具

### search_cases.py - 文档检索工具

**功能**：在文档库中搜索相关文档。

**函数签名**：
```python
def search_cases(query: str, cases_dir: str = "cases") -> str
```

**参数**：
- `query`: 搜索关键词（空格分隔，如 "ESG 销售"）
- `cases_dir`: 文档目录路径（默认："cases"）

**返回值**：检索结果字符串，格式：
```
【来源：文件名.md | 匹配度：分数】
文档片段内容
---
【来源：文件名2.md | 匹配度：分数2】
文档片段内容2
```

## 重要规则（影响检索效果）

### 检索逻辑

1. **关键词拆分**：使用空格分隔，转换为小写进行匹配
2. **匹配方式**：OR 匹配（任意关键词出现即匹配）
3. **片段提取**：对每个匹配位置提取15行上下文（前7+匹配行+后7）
4. **匹配度计算**：统计每个片段中关键词的出现次数总和
5. **排序规则**：按片段匹配度降序排序
6. **返回数量**：Top 3 最匹配的片段（可能来自不同文件或同一文件的不同位置）

### 上下文返回规则（关键）

**返回的上下文范围**：
- **匹配行位置**：找到所有匹配关键词的行位置
- **上下文范围**：匹配行**前7行非空行 + 匹配行 + 后7行非空行**，共 **15行非空行**
- **排除空行**：上下文提取时跳过空行（只包含 `strip()` 后非空的行）
- **返回最匹配的三部分**：收集所有匹配位置的片段，按匹配度排序，返回 Top 3

**代码实现**：
```python
# 向前找7个非空行
non_empty_before = []
i = match_line - 1
while i >= 0 and len(non_empty_before) < 7:
    if lines[i].strip():  # 非空行
        non_empty_before.insert(0, i)
    i -= 1

# 向后找7个非空行
non_empty_after = []
i = match_line + 1
while i < len(lines) and len(non_empty_after) < 7:
    if lines[i].strip():  # 非空行
        non_empty_after.append(i)
    i += 1
```

**匹配度计算**：
- 计算每个片段中关键词的出现次数总和
- 按匹配度降序排序，返回 Top 3 片段
- 可能来自不同文件或同一文件的不同位置

**影响**：
- ✅ 优点：返回更多上下文，信息更完整；返回最匹配的片段而非文件
- ✅ 优点：同一文件的多个匹配位置都可能被返回
- ⚠️ 注意：上下文范围增大，可能包含更多无关内容

### 性能特点

- **文件读取**：逐文件全文读取（小文件场景下性能可接受）
- **匹配计算**：逐行扫描，时间复杂度 O(n×m)，n=文件行数，m=关键词数
- **适用场景**：案例文件 < 50 个，单个文件 < 1000 行

**使用示例**：
```python
result = search_cases("ESG 销售", "cases")
# 返回 Top 3 匹配文件，每个文件返回匹配位置的5行上下文
```

## 扩展新工具

1. 在 `tools/` 目录下创建新文件（如 `calculator.py`）
2. 实现工具函数
3. 在 `tools/__init__.py` 中导出
4. 在 `src/api/chat_service.py` 中注册工具调用逻辑
5. 在 `config/config.yaml` 的 prompt_template 中描述工具功能

**工具函数规范**：
- 函数名清晰描述功能
- 参数类型明确
- 返回值格式统一（字符串或字典）
- 包含错误处理
