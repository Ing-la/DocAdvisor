# scripts/ - 脚本目录

程序入口脚本，提供不同的使用方式。

## 脚本说明

### main.py - 命令行版本

**功能**：命令行交互式 ReAct Agent。

**使用方式**：
```bash
python scripts/main.py
```

**工作流程**：
1. 加载配置文件
2. 提示用户输入需求
3. 执行 ReAct 循环（Thought → Action → Observation）
4. 输出最终方案

**特点**：
- 适合调试和测试
- 实时显示推理过程
- 支持彩色输出

### tkinter_app.py - GUI 版本

**功能**：Tkinter 图形界面版本的 ReAct Agent。

**使用方式**：
```bash
python scripts/tkinter_app.py
```

**界面功能**：
- 输入框：输入用户需求
- 推理过程显示：实时显示 ReAct 推理步骤
  - **检索结果优化显示**：检索结果只显示前3行，超过3行时显示"查看详情"链接（蓝色、下划线），点击可弹出窗口查看完整内容
  - 支持复制检索结果内容
- 最终方案显示：显示生成的方案
- 对话历史显示：显示多轮对话历史，可点击"查看详情"查看完整回答
- 清空按钮：一键清空所有内容
- 新建对话按钮：清空历史，开始新对话
- 模型配置按钮：配置大模型 API Key 和模型选择

**特点**：
- 用户友好的图形界面
- 多线程处理，避免界面冻结
- 实时更新推理过程
- 检索结果智能显示，保持界面简洁

## ReAct 循环逻辑

两个脚本都实现了相同的 ReAct 循环：

```
1. Thought: Agent 分析需求，决定下一步行动
2. Action: 调用工具（如 search_cases）
3. Observation: 获取工具返回结果
4. 重复步骤 1-3，直到生成 Final Answer
```

## 重要规则（影响效果和性能）

### 循环控制参数

**最大步数**：
- 默认：**6 步**（可在 `config/config.yaml` 中配置 `max_steps`）
- 影响：防止无限循环，但可能提前终止
- 达到最大步数时：强制生成通用方案（不基于检索结果）

**早停条件**：
- 检测到 `Final Answer:` 且无 `Action:` 时立即停止
- 影响：提高效率，避免不必要的工具调用

### 历史记录管理

**历史记录保留**：
- 保留最近 **15 条**历史记录（`state.history[-15:]`）
- 分隔符：`"\n---\n"`
- 影响：
  - ✅ 控制 prompt 长度，避免超出 token 限制
  - ⚠️ 超过 15 条的历史会被丢弃

**历史记录内容**：
- 多轮对话历史（最近3轮）
- Agent 回复（Thought + Action）
- Observation（工具返回结果）

**历史记录传递机制**：
- 每次循环时，将当前轮次的所有 Thought + Action + Observation 传递给下一次循环
- Observation 会在执行后立即添加到历史记录，下一次循环时 LLM 可以看到
- Prompt 强制要求 LLM 首先检查历史记录，避免重复检索

### LLM 输出解析规则

**格式检测**：
- 检测 `action:` 和 `final answer:`（不区分大小写）
- 如果同时出现：**仅执行 Action 部分**，忽略 Final Answer（防止跳步）

**JSON 解析**：
- Action 必须是有效的 JSON 格式
- 支持数组格式：`[{"tool": "...", "args": {...}}]`
- 支持对象格式：`{"tool": "...", "args": {...}}`
- 解析失败：要求 LLM 重新输出

**错误处理**：
- JSON 解析失败：追加错误信息到 history，继续循环
- 工具执行异常：追加错误信息到 history，继续循环
- 未知工具：返回错误信息

### 性能特点

**单次循环耗时**：
- LLM API 调用：通常 2-5 秒（取决于网络和模型）
- 工具调用：通常 < 100ms（本地文件检索）
- 总耗时：6 步 × 3秒 ≈ 18 秒（最坏情况）

**优化建议**：
- 减少最大步数（如果通常 2-3 步即可完成）
- 优化 prompt，引导 LLM 更快找到答案
- 添加结果缓存（避免重复检索）

## 工具调用机制

**当前支持的工具**：
- `search_cases`: 文档检索

**工具调用格式**：
```json
{"tool": "search_cases", "args": {"query": "关键词"}}
```

**扩展新工具**：
1. 在 `src/tools/` 中实现工具函数
2. 在脚本的 ReAct 循环中添加工具调用逻辑
3. 在 `config/config.yaml` 中更新 prompt_template，描述新工具
